# Card Duel — Data Structures C Project

A turn-based 1v1 card battle game demonstrating key data structures in C.

## Data Structures Implementation
- **Array:** Master card template pool.
- **Stack (LIFO):** Draw pile & discard pile.
- **Queue (FIFO):** Turn scheduling engine (round-robin player vs AI).
- **Linked List:** Dynamic hand management for drawing and discarding cards.
- **Insertion & Sorting:** Hand auto-sorting by power level and leaderboard persistence.
